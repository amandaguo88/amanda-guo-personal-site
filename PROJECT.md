# Personal Website — Project Context

## Project Goal

Build a personal website that presents Amanda Guo as a product-minded technologist
with a strong foundation in software engineering and design, and an increasing
interest in AI.

The website should make Amanda's multidisciplinary background feel coherent
rather than fragmented.

The central idea is:

> I work at the intersection of product, technology and people.

Amanda's experiences span software engineering, design, product, consulting and
technology enablement. Working across these disciplines has taught her to connect
perspectives, navigate ambiguity and turn complex problems into products and
experiences that work.

## Target Audience

- Product hiring managers
- Technical product hiring managers
- Engineering and design managers
- Technical recruiters
- People interested in Amanda's work

## Positioning

The website should communicate that Amanda:

- Connects perspectives across product, design, engineering and business
- Works effectively across different teams and stakeholders
- Is comfortable navigating ambiguity and constraints
- Can connect strategy to execution
- Combines technical depth with user empathy
- Can move between understanding problems and actually building solutions

The website should NOT position Amanda simply as a software engineer,
designer, or product manager. Her multidisciplinary perspective is a key
differentiator.

## Design Direction

Overall feeling:

- Minimal
- Technical
- Playful
- Sophisticated
- Editorial

Visual boldness:

- Balanced

Personality:

- Personal-professional

Colour:

- Inspired by Amanda's existing portfolio website
- Primarily neutral with a distinctive accent colour
- Colour system should be centralized and easy to customize

Animation:

- Subtle and purposeful
- Hover states
- Gentle transitions
- Scroll-based reveals where useful
- No animation-heavy or distracting effects

The site should feel polished and editorial rather than like a conventional
resume or corporate portfolio.

## Content Principles

The website should tell a story rather than simply reproduce a resume.

Experience titles should emphasize the problem, perspective or value of the
work rather than relying only on job titles.

Avoid excessive text. Visitors should be able to understand the main idea of
each experience quickly, with additional detail available through the page.

Do not invent achievements, responsibilities or technologies that are not
supported by the provided content.

## V1 Technical Scope

- Static website
- Next.js
- TypeScript
- Tailwind CSS
- Responsive
- Accessible
- Basic SEO
- Reusable components
- Centralized design tokens / CSS variables
- Content stored in the codebase

## Explicitly Out of Scope for V1

- Chatbot
- AI functionality built into the website
- Authentication
- Database
- CMS
- Dark mode
- Advanced animation
- Complex backend functionality

## Development Principles

- Prefer simple solutions over unnecessary abstractions
- Use reusable components where repetition exists
- Keep components focused and understandable
- Use semantic HTML
- Prioritize accessibility
- Make the site responsive from the beginning
- Avoid hardcoding repeated design values
- Keep colours, typography and spacing easy to customize
- Do not add dependencies unless they provide clear value
- Explain unfamiliar code or architectural decisions when asked
- Do not make large changes without first explaining the approach

## AI Development Principles

AI is being used as a development assistant and learning tool.

When implementing features:

1. Understand the requirement
2. Propose an approach
3. Explain important architectural decisions
4. Implement
5. Test
6. Review and refine

When debugging, explain the underlying cause before suggesting a fix when
practical.

Do not generate large amounts of unnecessary code.

The developer should understand the code being added to the project.

## Visual Identity

The visual direction is "Editorial Technologist."

The site should feel like a personal editorial publication created by someone
who builds technology.

Core tension:

> Technical structure + human personality

### Visual characteristics

- Minimal
- Editorial
- Sophisticated
- Technical
- Playful
- Personal-professional

### Colour

Use a warm/off-white neutral background and near-black/charcoal text.

Use the existing portfolio's pink/red colour as the primary brand accent.

The accent should appear intentionally throughout the interface, including
links, labels, hover states, section markers and selected typography.

Do not overuse the accent.

Do not use generic gradients, glassmorphism or futuristic AI visual effects.

### Typography

Use a distinctive editorial display typeface paired with a clean sans-serif
for body text.

Large typography should be a major part of the visual identity.

Use small uppercase labels with subtle letter spacing for metadata.

### Layout

Use generous whitespace, strong typography and occasional asymmetry.

Avoid making every section a collection of cards.

Prefer editorial layouts, lines, whitespace, large numbers and typography over
decorative UI.

### Brand Motif

The idea of "intersection" should subtly influence the visual system.

Use visual relationships such as:

- crossing lines
- overlapping elements
- × symbols
- connected sections
- typography that emphasizes relationships between ideas

Do not use literal Venn diagrams or overly obvious metaphors.

### Experience

Experience entries should feel like editorial stories rather than project
cards.

Emphasize the framing statement over the job title.

Use numbered entries:

01 — Manulife
02 — Deloitte Digital
03 — Wealthsimple
04 — Arctic Wolf

### Avoid

- Generic SaaS landing page aesthetics
- Excessive rounded cards
- Glassmorphism
- Gradient blobs
- 3D objects
- Generic AI imagery
- Excessive pills
- Excessive animations
- Decorative elements without purpose

## Signature Visual Concept — The Connecting Thread

The central visual concept of the site is "The Connecting Thread."

Amanda's career is defined by connecting perspectives that often sit apart:

- Product and engineering
- Design and technology
- Business strategy and execution
- Users and technical constraints
- Organizational goals and technology teams

The website should visually express this idea.

### Visual language

Use a subtle recurring visual thread or connection system throughout the
website.

This can be represented through:

- Lines
- Nodes
- Intersections
- Typography relationships
- The × symbol
- Shared alignment
- Connecting elements between sections

The visual system should feel sophisticated and editorial, not diagrammatic
or corporate.

### Hero

The intersection of PRODUCT × TECHNOLOGY × PEOPLE should be a meaningful
visual composition rather than simply text in a conventional hero layout.

The hero should be the strongest visual moment on the homepage.

### Experience

The featured experiences should feel like connected chapters in one career
story rather than four independent portfolio cards.

A visual timeline or connecting thread can connect the experiences.

### Typography

Use occasional dramatic changes in scale.

Typography can break the conventional grid when it creates a clear visual
purpose.

The words "intersection", "connect", or key experience framing statements
can become large visual elements.

### Personality

The site should contain small moments of playfulness and interaction.

Examples:

- Hovering over the × symbol
- Interactive connection lines
- Experience numbers responding subtly to hover
- Unexpected typography placement
- Small playful microcopy

These should feel intentional and personal rather than decorative.

### Restraint

The site should remain clean and sophisticated.

Do not use generic visual decoration to create personality.

Avoid:

- Gradient blobs
- Glassmorphism
- 3D objects
- Generic AI imagery
- Fake terminal interfaces
- Excessive animation
- Decorative elements without conceptual purpose
